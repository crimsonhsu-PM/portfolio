# 作品集連結頁

將 GitHub Pages 的公開入口導向作品集展示頁，並提供手動連結。

## 功能

- 自動導向作品集
- 導向失敗時提供可點擊連結
- 分享預覽文字與封面圖

Demo：https://crimsonhsu-pm.github.io/portfolio/

## 本機啟動

```bash
git clone https://github.com/crimsonhsu-PM/portfolio.git
cd portfolio
python3 -m http.server 8000
```

瀏覽 http://localhost:8000 ，會導向外部作品集頁。維護說明見 [HANDOFF.md](HANDOFF.md)。
