讓機台接上外部線上遊戲：三方介接從釐清到上線

專案管理

實體遊戲機要接入外部的線上遊戲，牽涉機台、雲端錢包、外部遊戲平台三個系統和五個團隊。我從需求釐清開始，一路推到大家有同一份開發與測試的依據；實際串接由後端工程師實作。

  1. 01需求釐清3 個系統的資料流向機台、雲端錢包、外部遊戲平台之間，餘額何時轉入、何時轉回
  2. 02分工5 個團隊各做什麼企劃、後端、平台、QA 與外部廠商，各自要做哪些項目與 API
  3. 03召集會議確認 6 條例外規則延遲派彩、斷電重開等情境，逐條追到有結論
  4. 04產出開發與測試的依據交給後端工程師實作串接，QA 依此驗收
